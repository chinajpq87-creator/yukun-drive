# Real Asset Collection Standard

## Purpose

Replace abstract site visuals only with evidence that Yukun has permission to publish and can explain accurately.

## Asset priority

1. Approved product sample photography: full product, mechanism detail, interface detail, and scale reference.
2. CAD or technical drawings cleared for public use: remove customer dimensions, identifiers, and confidential layers first.
3. Test or prototype evidence: test setup, fixture, pre/post condition, and a factual caption describing only what is shown.
4. Packaging, inspection, assembly, or supplier-process photographs: only with site-owner permission and no hidden customer identifiers.
5. Customer outcome/case material: only with written permission and a customer-approved claim statement.

## Required record for every asset

| Field | Requirement |
| --- | --- |
| File name | Project-neutral, descriptive, versioned |
| Owner | Person or organization that owns the image/drawing |
| Permission | Written approval for website use, retained outside the public repository |
| Subject | Exact product, mechanism, test, or process shown |
| Date and place | Internal record only; publish only when appropriate |
| Public caption | Factual description of what is visible; no inferred performance claim |
| Restrictions | Markets, time period, customer anonymity, cropping, or no-logo requirement |

## Do not publish

- Customer drawings, BOMs, or samples without explicit written consent.
- Images that imply a factory is owned, certified, or exclusively controlled when that is not documented.
- Test footage that lacks setup, method, or context but implies a performance result.
- Supplier-site photography that reveals confidential production, worker personal data, customer names, or traceability labels.
- AI-generated image presented as product, factory, customer, test, or project evidence.

## First collection batch

Collect only these eight items before expanding the visual system:

1. One approved overall product sample photo.
2. One approved mechanism or component close-up.
3. One non-confidential drawing or CAD view.
4. One fixture or test-bench photo with a factual caption.
5. One assembly or inspection photo with permission.
6. One packaging or interface photo where relevant.
7. One short horizontal test clip, with no music and a factual on-page caption.
8. Written authorization or internal ownership record for every file.

Upload only cleared, original files. Website processing should create optimized copies; the original evidence should remain in controlled storage.
